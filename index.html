1. BASIC FARMING AUTOMATION

Equip a Farming Module on your drone to till, water, plant, crop, or harvest plants. Use loops to automate simple agriculture tasks.

FARMING SNIPPET: Loop farm a row of wheat
// Till, water, and plant a row of 5 wheat seeds
for (var i = 0; i < 5; i++) {
  drone.till();
  drone.water();
  drone.plant('wheat');
  drone.move('right');
}

2. CAVE MINING & ORE DRILLING

Unlock the Mining Key at the Shop and interact with the Cave Gate to unlock Zone 3. Equip a Mining Module on your drone to mine ore veins (Coal, Copper, Iron, Gold) at the lower cavern area (X: 0-39, Y: 20-39). A mining drone has a 2.5x Drill Modifier that boosts rare ore drop weights!

Use drone.checkNode() to scan the geology underneath, and drone.mine() to extract the ore block. Ore veins are located at specific sites: Coal (5,25), Copper (15,30), Iron (25,32), Gold (35,35).

MINING SNIPPET: Scan and mine node until empty or full
// Scan the geology, drill until depleted or full
var ore = drone.checkNode();
if (ore !== 'none' && ore !== 'depleted') {
  while (!drone.isInventoryFull() && drone.checkNode() === ore) {
    drone.mine();
    drone.wait(0.5); // small action delay
  }
  drone.say("Done mining! Count: " + drone.getInventoryCount());
}

3. SUPPLIER DRONES & LOGISTICS

Equip a Supplier Module to transfer items between adjacent drones or automate refineries. Use drone.supplyFrom(otherDroneId) to pull items from an adjacent drone. Use drone.depositToConveyor(item), drone.checkFrontItem(), and drone.pushItem(direction) to manage a conveyor line.

LOGISTICS SNIPPET: Sorter gate logic router
// Route coal/iron to smelter (right) and others to warehouse (left)
while (drone.hasPower()) {
  var cargo = drone.checkFrontItem();
  if (cargo === 'iron_ore' || cargo === 'coal') {
    drone.pushItem('right');
  } else if (cargo !== 'none') {
    drone.pushItem('left');
  } else {
    drone.wait(1.0);
  }
}

4. SELLER DRONES & NPC BUYERS

Equip a Seller Module to buy seeds or sell inventory items using drone.buy(crop, count) and drone.sell(). A seller must stand beside the Market before selling. You can also deliver orders to Special NPC Buyers who arrive at the dock (adjacent to X:17, Y:3) for 2.0x value rewards!

SELLING SNIPPET: Fulfill special guest NPC orders
// Deliver requested crop to special guest NPC
if (drone.hasSpecialBuyer()) {
  var order = drone.getSpecialBuyerRequest();
  if (drone.hasDroneItem(order.reqItem, order.reqCount)) {
    drone.say("Delivering order to guest!");
    drone.deliverToSpecialBuyer();
  }
}

5. GLOBAL STATE & SHARED MEMORY (MEMSET STATE)

Coordinate multiple drones using the global shared memory object mem. Use mem.set(key, value) and mem.get(key, defaultValue) to read/write state flags or share coordinates across different drone script playgrounds.

MEMSET STATE SNIPPET: Coordinate miners and transporters
// Drone 1 (Miner): Set flag when full of iron
if (drone.isInventoryFull()) {
  mem.set('iron_ready', true);
}

// Drone 2 (Transporter): Read flag, go collect, then clear flag
var needsTransport = mem.get('iron_ready', false);
if (needsTransport) {
  drone.say("Moving to transport iron!");
  mem.set('iron_ready', false); // clear flag
}

6. CENTRALIZED WAREHOUSE SYSTEM

The centralized Warehouse (Zone 1, purple base structure at X:10, Y:2) offers infinite storage capacity. Craft a Depot kit at a Crafting Table to add another access point to the same shared stock.

  • Autonomous Drones: Drones can deposit items directly into the Warehouse using drone.transferToWarehouse() when standing adjacent to the Warehouse.
  • Manual Warehouse Panel: Press [E] beside HQ or a Depot. The code sidebar becomes a two-column storage dock: drag a full stack, Shift + drag one item, or use Split to choose a quantity.
  • Automated Pickup: Use drone.transferFromWarehouse('wheat') beside HQ or a Depot. It pulls that item until the drone is full or the stock runs out.

7. SELLER ROUTE: WAREHOUSE → MARKET

A Seller/Buyer drone can fill its cargo at Warehouse, fly to the Market, then use drone.sell(). Selling only works beside the Market, so route the drone back to Warehouse to repeat the loop.

8. EXPLORE ZONE & PASSIVE FAUNA

Open the south gate from the Mining Cave with 10 stone and 2 iron ingot. Wildlife is passive: it wanders and leaves Wild Fiber on the ground. A drone can read the tile with drone.checkGround() and collect it with drone.collect().

DRONE API REFERENCE
CATEGORY: NAVIGATION & FARMING
drone.move(dir)
Moves drone 1 tile: 'up', 'down', 'left', 'right'.
drone.till()
Tills grass soil at drone's tile.
drone.water()
Waters tilled soil.
drone.plant(crop)
Plants seed (e.g. 'wheat', 'potato', 'cactus', 'apple_tree').
drone.crop()
Harvests mature standard crops (Wheat, Potato) and clears the tile.
drone.harvest()
Picks fruit from trees (Apple, Cactus) without clearing the plant.
drone.canCrop()
Returns true if standard crop under drone is mature.
drone.canHarvest()
Returns true if fruit tree has ripe fruit.
drone.isWatered()
Returns true if tile is watered.
drone.isTilled()
Returns true if tile is tilled.
CATEGORY: CAVE MINING
drone.checkNode()
Scans geology underneath: returns 'stone', 'iron_vein', 'coal_seam', 'depleted', or 'none'.
drone.mine()
Drills ore node. Lowers durability, yields ore block, triggers cooldown.
drone.isInventoryFull()
Returns true if drone inventory count is maxed.
drone.getBatteryLevel()
Returns remaining script battery steps.
CATEGORY: MACHINES & CONVEYOR LOGISTICS
drone.checkFrontItem()
Returns item ID of cargo directly 1 tile in front of the drone on a conveyor belt.
drone.pushItem(dir)
Pushes the item in front of the drone to a matching conveyor direction.
drone.depositToConveyor(item)
Places one carried item on the empty conveyor directly in front of the drone.
drone.getMachineState(id)
Returns object state of a refinery machine (inputs list, outputs list, isProcessing status).
drone.depositToMachine(id, item, qty)
Deposits item from drone inventory into machine's input buffer.
drone.retrieveFromMachine(id)
Pulls all outputs inside refinery machine into drone inventory.
CATEGORY: SUPPLIER DRONES & WAREHOUSE
drone.checkGround()
Returns the explore-zone drop at the drone's current tile, or 'none'.
drone.collect()
Collects the resource drop beneath the drone, if there is room in its inventory.
drone.transferToPlayer()
Moves all drone items directly to the player's backpack.
drone.transferToWarehouse()
Deposits all drone items into shared storage. Drone must stand adjacent to HQ Warehouse or a crafted Depot.
drone.transferFromWarehouse(item)
Loads the selected item until the drone reaches capacity or Warehouse stock runs out. Drone must stand adjacent to HQ Warehouse or a crafted Depot.
drone.supplyFrom(otherId)
Pulls all items from an adjacent drone's inventory. Requires **Supplier Module **.
CATEGORY: SELLER DRONES & NPC BUYERS
drone.sell()
Sells all sellable cargo beside the Market. Requires a Seller/Buyer Module.
drone.buy(seed, qty)
Buys seeds from shop directly into drone. Requires **Seller Module **.
drone.hasSpecialBuyer()
Returns true if a special guest buyer NPC is active at the market.
drone.deliverToSpecialBuyer()
Fulfills the guest NPC request. Requires standing adjacent to buyer at Market.
CATEGORY: COORDINATION & SHARED MEMORY
mem.set(key, value)
Saves state value in shared memory board. Accessible by all drones.
mem.get(key, default)
Reads state from shared board. Returns default if key is missing.
mem.inc(key, amount)
Atomically increments/decrements a shared numeric counter.
drone.getDrones()
Returns list of active drones and their positions.
